# Changelog

## 0.6.0

- First Marketplace release candidate under `StackStats.stack-stats-vscode`.
- Local coding activity, sessions, languages, projects, streaks and workflow analytics.
- Optional account linking and private summary sync, with public sharing controlled separately on stackstats.dev.
- Local agent activity and confirmed, one-click Claude Code and Codex integrations.
- Minimal, Moderate and Extensive tracking levels, advanced controls and a privacy summary.
- Stack Stats branding for the Marketplace and Activity Bar.
- Fix desktop account sign-in URL encoding when VS Code adds a window identifier.

Beta VSIX users: back up local history before removing the old extension. The new publisher creates a separate storage and credential namespace; sign in and approve sync again. See the [migration guide](https://github.com/userN7590/stack-stats/blob/main/docs/PHASE-10B-RELEASE-CANDIDATE.md).
